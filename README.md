## 🚀 Features

- **📖 Curated E-Book Catalog**: Across Tech & AI, Sci-Fi & Fantasy, Business, Self-Help, Psychology, Design, and Fiction.
- **🔍 Instant Live Search & Multi-Format Filtering**: Search by title, author, keyword, or synopsis. Filter by format (`.EPUB`, `.PDF`, `.MOBI`).
- **👓 In-Browser Interactive Sample Reader**: Read Chapter 1 directly in browser with **Light, Sepia, and Night** themes, plus dynamic font sizing.
- **🛍️ Persistent Shopping Bag & Promo Engine**: Slide-out cart drawer with instant promo code validation (use code `BOOKFORU20` for 20% off).
- **💳 Streamlined Checkout & Instant File Delivery**: Clean accessible checkout with test gateway simulation and immediate downloadable receipts.
- **📱 Universal Device Guides**: Step-by-step instructions for Amazon Kindle ("Send to Kindle"), Apple Books, Android, and Kobo.

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Steelthings1/bookforU.git

# Navigate into the project folder
cd bookforU

# Install dependencies
npm install

# Start development server
npm run dev

# Or build for production
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the website.
